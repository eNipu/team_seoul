# T62 — Link to ChatGPT from web home

Add an **Open ChatGPT Plugin** link beside the greeting on both the signed-in dashboard and the first-run welcome screen. Point it to `https://chatgpt.com/plugins` and put a help icon beside it that opens the [Venn Quickstart Guide](../Venn-Quickstart.pdf) in a new tab. Keep the two links together when they wrap below the greeting on narrow screens.
