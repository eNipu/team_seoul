# T51 — Venn Overlap

A web-only opt-in lane for meeting one other Venn member over a small activity. Match the plan before showing the people. Keep the existing circle, memory consent and chat recommendations separate.

- Home (welcome and dashboard) opens Overlap. Adults explicitly pick one Seoul neighborhood, one date/window and 1–3 public interest tags. No device location or private memory inference.
- Only match eligible opt-ins in the same area/window with a shared interest; exclude connections, blocks and previously passed pairs. Display one anonymous plan with a factual reason.
- One yes stays one-sided. Two yeses reveal first names and a shared challenge to both members. After introduction, either person can suggest a predefined public meeting point/time; both must separately agree to mark it agreed. No friendship, message, calendar event or booking is created.
- Pass, withdraw, block and report must be effective server-side. Expired opt-ins are invisible. No public people directory, raw bio exchange, or contact upload.
- Test isolation, expiry, mutual consent, concurrent matching and report/block behavior. Rehearse with two distinct accounts or two explicitly fictional demo seats.
