# T63 — Save a neighborhood for Overlap during web onboarding

- On the web welcome screen, users can optionally save one of Seongsu, Hongdae or Yeonnam. No default, GPS or address. Users can edit or remove the preference from Account.
- Store the choice privately on the signed-in account. Overlap offers it as a shortcut but starts with no selected neighborhood: the user must choose one for each new window and explicitly opt in.
- Changing or removing the saved neighborhood never changes a window already opened. Only the window’s selected neighborhood participates in matching.
