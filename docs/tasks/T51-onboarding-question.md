# T51 · First onboarding question

**Goal.** Give someone opening Venn a concrete question they can answer in one sentence.

**Read first**

- `backend/app/services/dashboard_service.py`, `backend/app/mcp/server.py`
- `plugin/skills/venn-social/SKILL.md`, `docs/MCP_TOOLS.md`

**Done when**

- The welcome tool result supplies a question about one person and a shared activity.
- Venn accepts partial answers and offers the usual memory review.
- Starting with a specific request still takes precedence. Once the user saves a memory,
  dashboard guidance moves to the next open step.
- The welcome card also lets people start with names, review their choices, and open the Friends tab.
- MCP initialization supplies Venn's description, website, and icon for compatible hosts.
- Namesakes can be reviewed with relationship clues. An ambiguous name alone cannot assign a memory to a friend.
