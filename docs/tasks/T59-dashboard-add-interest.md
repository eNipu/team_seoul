# T59 — Add an interest from the ChatGPT dashboard

Put **Add interest** in the Profile tab’s Interests section. Submit the user’s text as a single `INTEREST` candidate via `venn_propose_memories`, then use the existing review card. Saving needs explicit confirmation and defaults to private. A saved interest appears under Profile and in Memories.

Check `?view=dashboard&tab=profile` at narrow and wide widths, and run the widget typecheck and build.
