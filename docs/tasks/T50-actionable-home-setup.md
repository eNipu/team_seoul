# T50 — Complete setup from Home

Make the web Home checklist an entry point to setup, on both the welcome screen and the dashboard. Link unfinished steps to the existing memory, person, and invite flows. Keep completed steps noninteractive and derive completion from saved data, never the click itself.

Verify in `/app?demo=1&fresh=1`: cancel the first step, then save a memory, add a person, and create an invite. Return to Home and check progress after each action. Loading sample data should not complete these steps.
