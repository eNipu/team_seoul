# Findings

- **fnd_1** The primary onboarding API endpoint is POST /api/onboard/text, called when users submit their contact information to talk with Boardy. The request sends JSON containing email, phone, honeypot website field, UTM parameters, and intent, and returns a verified phone number, pre-filled SMS body text, and a QR code data URL. (Seen it; evidence: ev_b2985baf12b74e94f6207c8e4ddffcd95a5d6b1940e8687b273a37690b363b78, ev_ca1a25bdd21c2674d33702f98db21b4d9fc1d5768c61db5a7459b5ffc1f050df)
- **fnd_2** The homepage dynamically polls GET /api/public-globe using fetch with an AbortController (8-second timeout) and IntersectionObserver when the globe is visible. The response supplies recent introduction metrics and geographical coordinate routes used to animate the interactive globe. (Seen it; evidence: ev_fbf1da350c4b08d1047754397336a8c6094f99d13c6e52509dc51c7a1313478f, ev_ca1a25bdd21c2674d33702f98db21b4d9fc1d5768c61db5a7459b5ffc1f050df)
- **fnd_3** Third-party analytics and integration calls include PostHog (feature flags, surveys, product tours, experiment tokens), Sentry monitoring, and marketing attribution pixels. Scheduling interactions route to the dedicated cal.boardy.ai service for booking pages and calendar synchronization. (Seen it; evidence: ev_b2985baf12b74e94f6207c8e4ddffcd95a5d6b1940e8687b273a37690b363b78, ev_b428382b62a4997914a0d48a14cd485d466a5ee1f4543b15c393134f2a4840c8)
